# Jason's Days Detector

「13日の金曜日」（ジェイソンの日）を自動検出する Go プログラムです。

## 概要
現在の日時を基準として、指定された将来の期間内に発生する「13日の金曜日」を検出し、日時を出力します。

## 必要要件
- Go 1.27.4 以上

## 使い方

### 実行方法
以下のコマンドでプログラムを実行します。

```bash
go run main.go -y <検出する年数>
```

#### オプション
- `-y` (int): 検出対象とする将来の年数（デフォルト: `3`）

#### 実行例
```bash
$ go run main.go -y 1
2026-06-24 15:00:00 +0900 JST
ジェイソンが出現する日です
2026-11-13 15:00:00 +0900 UTC
2027-08-13 15:00:00 +0900 UTC
```
